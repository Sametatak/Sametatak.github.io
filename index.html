Repository Spotlight

MPPI ROS2 Navigation Planner

This repository packages a ROS2 navigation prototype around a Python MPPI controller. The stack publishes visualization topics for sampled rollouts, the selected trajectory, costmap data, and target markers so the behavior can be inspected directly in RViz while Gazebo runs the scene.

  • Diff-drive kinematic model with sampled velocity commands.
  • Cost function balancing target distance, heading error, and obstacle cost.
  • Simple global planner and pure-pursuit lookahead target selection.
  • Launch flow for costmap, global planner, MPPI controller, and RViz.
Open on GitHub ↗

Controller

Samples candidate velocity rollouts, scores them, and shifts the nominal control sequence forward each cycle.

Visualization

Publishes rollout markers, best trajectory, goal marker, target marker, and occupancy grid views for RViz.

Simulation

Pairs Gazebo obstacle scenes with RViz inspection to tune navigation behavior in a repeatable environment.
